Abstract
This article demonstrates MyST Markdown integration with Elsevier’s CAS
and elsarticle classes, covering typography, math, cross-references, admonitions,
proofs, tables, figures, and code blocks.

1. Introduction
This document demonstrates the full integration of MyST Markdown (Cockett et al., 2024) with Elsevier’s CAS templates. MyST provides a powerful authoring experience while maintaining compatibility with traditional LaTeX journal requirements (Lamport, 1994). The template renders to PDF for cameraready submission and to HTML for the project website; author identifiers (ORCID) and persistent links (DOI) propagate through both pipelines.
1.1. Background
Scientific publishing has traditionally relied on LaTeX for high-quality typesetting (Krewinkel and Winkler, 2017). However, the learning curve and complexity of LaTeX can be a barrier for authors who write outside it day to day.
MyST Markdown bridges this gap by providing:
1. A familiar Markdown syntax based on CommonMark (Gruber, 2004)
2. Rich scientific features (equations, citations, cross-references)

6. Code Blocks
Code blocks with syntax highlighting are supported:
import numpy as np
from typing import Tuple
def quadratic_formula(a: float, b: float, c: float) -> Tuple[float, float]:
"""Solve ax^2 + bx + c = 0 using the quadratic formula."""
discriminant = b**2 - 4*a*c
if discriminant < 0:
raise ValueError("No real solutions")
x1 = ( -b + np.sqrt(discriminant)) / (2*a)
x2 = ( -b - np.sqrt(discriminant)) / (2*a)
return x1, x2
# Example usage
roots = quadratic_formula(1, -5, 6)
print(f"Roots: {roots}") # Output: (3.0, 2.0)

11. Discussion
This approach enables researchers to write in MyST Markdown while producing publication-ready documents that meet Elsevier’s submission requirements.
11.1. Advantages
1. Reproducibility: Source files are plain text and version-controllable
2. Flexibility: Single source exports to HTML, PDF, and other formats
3. Modern tooling: Integration with Jupyter, VS Code, and other tools
4. Rich features: Full LaTeX math, cross-references, and citations
11.2. Limitations
Warning
Some MyST features render only in HTML output. For PDF, consider
using LaTeX-compatible alternatives.
